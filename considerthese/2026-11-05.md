## 3 lessons / coverage gains (from the curation branch; candidate only)

1. **Navigation baking is a new frontier with two complementary sources** (`2026-11-03-curated-sources.md`). Godot's NavigationMesh baking tutorial (method) and Recast Navigation source and unit tests (algorithm, pinned reading anchor `9f4ce644`). The lesson is that agent-center navigable surfaces differ from physics collision bounds, so a path proving "connected" does not prove "collision-free". The proposed exercise is an original narrow-corridor radius sweep with an excluded-source-group control. Upstream Recast is not necessarily Godot's bundled revision, so no cross-engine equivalence is claimed.
2. **Mesh pipeline contracts: simplify, unwrap, tangent** (`-02` meshoptimizer pinned `9e1f07b1`, `-03` xatlas pinned `f700c779`, `-04` MikkTSpace pinned `3e895b49`). Each names a contract that a transformation can silently break: border locks and absolute/relative error units; seam-duplicated vertices needing remap via the input-vertex reference and texel-vs-normalized UVs; per-corner tangent data that must not be averaged or index-welded. Each comes with a negative control (permissive-mode counterexample, copy-by-output-index, position-only weld). This is the strongest depth gain: it widens the lane from import/render/physics to asset-transform correctness.
3. **Convention-aware depth: old and new both stay valid** (`-05`, conventional depth to reverse-Z). A timeline pairs Godot 4.2 docs, the NVIDIA mechanism article, the 4.3 reverse-Z announcement and 4.7 docs (near=1, far=0, Forward+/Mobile vs Compatibility NDC). The lesson is calibration: do not apply the new near/far convention to an unknown captured buffer by analogy, and keep algebraic, quantization and rendered Z-fighting claims separate. It links directly to the merged three.js `lookAt`/frustum conventions work (PR #4).

Cross-cutting discipline in all five files: sources are pinned by commit or version, dates and ages are stated, licenses are noted separately from training and asset rights, and every "later exercise" is explicitly marked as not performed.
