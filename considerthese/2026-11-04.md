## 3 lessons / capability gains (from the Oct 30 PRs)

1. **`lookAt` has opposite facing axes for cameras and plain objects** (PR #4, `corpus/fixtures/three/lookat_orientation.mjs`, 5 cases, runner `run_lookat_cases.mjs`, README section in `ede67979`). With the same call, a `PerspectiveCamera` faces -Z toward the target while a plain `Object3D` faces +Z (`toward_dot=1.000`). Engine values matched hand-derived closed forms: camera x-basis `(-2,0,1)/sqrt(5)`, y-basis `(-1,5,-2)/sqrt(30)`, up-probe NDC `sqrt(5)/13 = 0.172`. Three negatives (`camera_plusz`, `object_minusz`, `flipped_up`) are rejected with exit 2. This is a high-value convention trap for the lane.
2. **World-space bounds vs local bounds, plus ray pretest agreement** (PR #3, `corpus/fixtures/three/box3_bounds.mjs`, 5 cases, runner `run_box3_cases.mjs`, README in `df2ce344`). A 2x1x1 mesh rotated 45 degrees about Z gives AABB half-extent `cos45 + 0.5*sin45 = 1.06066`, bounding-sphere `r2 = 2.5`, and a probe hit at 5.04289. `Ray.intersectsBox` agrees with the mesh raycast on a hit and a miss. Negatives cover a stale box (`stale_box`) and local-vs-world confusion (`local_world`), and `mutate_expand` is a mutation control that must fail with exit 1.
3. **Contribution discipline: exact exit/stream contract with an honest evidence boundary.** Both PRs reuse the 0/2/1 exit contract, exact marker lines, and seed SHA-256 digests (same pattern as `run_ray_cases.mjs`), and both state "browser-executed against pinned three 0.186.1; lane-host receipts pending" and deliberately leave `run_battery.py` case counts untouched. That is good calibration: measured vs inferred is labeled. It also leaves a receipt debt (see ideas).
