# games-engine-mechanics — fixture corpus

Reference corpus of the **games-engine-mechanics** research direction from the
prymeagnt craft campaign (2026-10-11/12): a bounded headless Godot 4.7.2
fixture suite — synthetic input, physics overlap, causal chains, scene
transitions, discriminating negative controls — plus its round reports.

Purposes: (1) reference guide — every fixture carries its exact reproduction
command and expected exit signature; (2) discovery corpus for new mechanics
moves; (3) inspiration source — failed integration rounds (r6/r7/r9) are
preserved as negative results.

Upstream: https://github.com/VeigaPunk/prymeagnt-games-engine-mechanics (branch main carries this
corpus; craft/games-* branches carry round-by-round history). Local execution
references it with: git fetch games-engine-mechanics main
