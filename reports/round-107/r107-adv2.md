## 4. Harness defects found in ADV1's own scripts (reported, not fixed in place)

**[O] Subshell exit-code bug in `adv1-C/D/F-*.sh`.** Each calls
`run_gate "$MIRROR" | grep -E '^(…|GATE RESULT)'`. A pipeline runs in a subshell, so `GATE_EXIT`
keeps the value from the last *baseline* run (0), and `verdict` therefore prints MISSED for every
row regardless of what the gate actually did:

```
$ sed -n '34p' adv1-C-declared-drift.sh
run_gate "$MIRROR" | grep -E '^(MANIFEST_OK|CARDS|POINTERS|GATE RESULT)'
$ grep -n '^  GATE_EXIT=\$?' adv1-lib.sh     # set INSIDE run_gate
```
`run_gate` sets `GATE_EXIT=$?` in its own scope; when its stdout is piped, that assignment happens
in the pipeline's subshell and is lost. `adv1-A/B/E` are unaffected (A and E use `show`; B prints
`exit=$GATE_EXIT` per sub-case). My scratch copies replace the pipe with `run_gate …; show '…'`,
which preserves `GATE_EXIT`. **Every ADV1 C/D/F row in §3 was re-measured with that fix**; the
live-gate MISSED verdicts are therefore real, not harness artifacts. [I] ADV1's own reported matrix
should be re-checked against this before its numbers are cited.

**[I] Cross-contamination in class C.** C1 and C2 share one mirror, so a draft that catches C1
leaves C2 unreported (the class verdict short-circuits). I re-ran C2 against a fresh mirror
(draft): `CARDS=13 … POINTERS … UNRESOLVED=0` → **C2 MISSED**. See §3.
